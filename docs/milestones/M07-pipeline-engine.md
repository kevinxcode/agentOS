
==================================================
MILESTONE 7 — PIPELINE ENGINE
==================================================

Pipeline concepts should include:

Pipeline
PipelineNode
PipelineEdge
PipelineRun

Useful node types:

PROMPT
AGENT
TOOL
CONDITION
PARALLEL
MERGE
APPROVAL
OUTPUT

Execution should be observable.

The UI must allow users to understand:

current node
completed nodes
failed nodes
logs
duration
outputs

Retries must be bounded.
